# Insights — what one workflow learned that the others should know

Cross-workflow memory. When a verdict, a rejected draft, or a pattern in the
numbers teaches you something that is not specific to one workflow — a hook
style that works, a truth about the audience, a claim that always lands or
always flops — write it here, one line each, newest on top.

Every workflow's loop pass should read this file, and add to it when an
insight generalises. Assets worth reusing (a winning image, a b-roll clip, a
proof point) go in `shared/assets/`; longer write-ups in `shared/docs/`.

Format: `YYYY-MM-DD · <source workflow/run> — the insight, one line.`
